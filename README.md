# Krishtii Jewellery — Royal Pink Edition

Fresh React + Vite jewellery website with a white/blush + royal pink/wine palette.

Included:
- Heavy bridal jewellery collection
- Kundan & Polki
- Temple jewellery
- Bangles and chura
- Jhumkas
- Jewellery rental section
- Customer reviews
- Instagram section
- Hover effects
- Call us buttons
- Responsive mobile design
- Working Vite React configuration

## Run
npm install
npm run dev

## Replace before client delivery
Update the demo phone number, Instagram URL, Rajkot address, prices, reviews, and image URLs in `src/App.jsx`.
